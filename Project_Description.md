# Marvel Character Selection Project

**Project Description:** 
The project that the professor approved for the team is a Marvel character website. Our target audience is fans who love Marvel. The existing problem is that Marvel character info is scattered across many different websites, making it hard to find consolidated data. Our project will address this by allowing users to search for Marvel characters in one place and view their descriptions, powers, and abilities. New information and activities provided to the audience will include a streamlined search interface and consolidated, easy-to-read character profiles.

**Epics & User Stories:**

### Epic 1: Character Search
**US-01: Search for a Marvel Character**
* **WHO:** As a Marvel fan
* **WHAT:** I want to look up a Marvel character by their name
* **WHY:** So I can quickly find the character I am looking for
* **GIVEN:** I am on the Marvel website
* **WHEN:** I type a Marvel character's name and search for it
* **THEN:** the website displays the matching character

**US-06: View Character Search Results**
* **WHO:** As a Marvel fan
* **WHAT:** I want to see the character that matches my search
* **WHY:** So I can find the Marvel character I am looking for
* **GIVEN:** I have entered a Marvel character's name into the search
* **WHEN:** I submit the search
* **THEN:** the website displays the matching character

### Epic 2: Character Selection
**US-02: Select a Marvel Character**
