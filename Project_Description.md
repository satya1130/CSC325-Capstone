# Marvel Clash — Updated Product Goal and Brawl Extension

## Revised Project Direction

Our CSC 325 project has developed from the original Marvel Character Selection Website into **Marvel Clash**, a character exploration and Brawler prototype.

The original features, including searching, browsing, viewing character information, comparing characters, saving favorites, and AI-assisted character recommendations, remain part of our project planning.

The updated Product Goal is:

**Make Marvel characters easy to explore and turn character comparisons into entertaining, understandable Brawls.**

Our Figma prototype demonstrates how users can explore 49 Marvel characters, inspect their powers and abilities, choose two fighters, and experience an example Brawl with moves, health changes, commentary, and an explained result.

## Updated Personas

**Primary personas:**

- **Aryan:** A normal user who is not necessarily a Marvel fan but wants to log in and use the website.
- **MarvelFan:** A registered Marvel fan who can sign in without a password in our demonstration and access member features.

**Secondary personas:**

- **Guest:** An unsigned visitor with limited access to the website.
- **Salih (Admin):** A user with normal member access plus restricted menus for project testing and experimentation.

## Current Prototype

Our Figma prototype includes character discovery, categorized browsing, character profiles, comparisons, favorites, two-fighter selection, example Brawls, result explanations, and account-role demonstrations.

The current prototype is an interactive design. It does not contain a deployed application, secure live account system, persistent database, or functional AI Brawl engine.

## Planned AI Brawl Engine

Our main future AI feature would use reviewed character data, including powers, moves, abilities, weaknesses and counters, to generate varied matchups.

The planned engine would track fighter health, damage, attacks, counters and turns, then explain the simulated outcome.

This would be a fan-made game simulation rather than official Marvel canon.

The earlier AI ideas, including character summaries, recommendations and character questions, remain possible future additions.

## Updated Sanity Check

The personas, context diagram, interface screens and primary user journey all support the revised Product Goal.

MarvelFan demonstrates the main workflow: signing in, discovering characters, reading profiles, comparing characters, choosing fighters, starting a simulated Brawl, and understanding the result.

The existing character-search and discovery work supports the newer Brawl features by helping users learn about characters before selecting a matchup.

Features that require a real database, server, or AI engine remain planned development, not completed functionality.
